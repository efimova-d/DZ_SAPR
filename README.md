# ДЗ по САПР: протез кисти руки миоэлектрический с обратной связью

**Выполнила:** Ефимова Д.С., группа БМТ2-31М, МГТУ им. Н.Э. Баумана
**Проверил:** Рязанцев П.
**САПР:** KiCad 10

```bash
git clone --recursive https://github.com/efimova-d/DZ_SAPR.git
```

## 1. Библиотека компонентов

- **Состав:** библиотека `GOST_ESKD` содержит 22 символа (УГО по ГОСТ ЕСКД) и 12 посадочных мест.
- **Подключение:** библиотека подключена как git-сабмодуль в `lib/GOST_ESKD`.
- **Пути:** относительные, в `sym-lib-table` и `fp-lib-table` проекта:
  `${KIPRJMOD}/lib/GOST_ESKD/GOST_ESKD.kicad_sym` и `${KIPRJMOD}/lib/GOST_ESKD/GOST_ESKD.pretty`.
- **Размеры УГО** соответствуют ГОСТ 2.728, 2.730, 2.736, 2.743, 2.755 и 2.759.
- **Линии УГО** той же толщины, что линии связи (ГОСТ 2.721).
- **Шрифт** — ГОСТ тип Б, выводы на сетке 2,54 мм.

## 2. Схема электрическая принципиальная

- **Формат:** A3, рамка и основная надпись по ГОСТ 2.104 (форма 1).
- **Обозначение:** БИГЕ.944421.001 Э3, литера «У».
- **Позиционные обозначения** — по ГОСТ 2.710; части многосекционного элемента обозначены через точку: DA2.1 … DA2.5.
- **ОУ DA1, DA2** — по ГОСТ 2.759: поля с обозначениями выводов (+IN, −IN, OUT, RG, REF, +U, −U), знак ▷∞; питание TL074 вынесено в отдельную часть DA2.5.
- **Разъёмы X1–X3** — табличная форма по ГОСТ 2.755 с графами «Конт.» и «Цепь».
- **Шины питания** +5 В, −5 В, +3,3 В и общий провод изображены по ГОСТ 2.702 и ГОСТ 2.721.
- **ERC:** 0 ошибок.

## 5. Печатная плата (технология «Резонит», DFMA)

**Параметры платы:**
- 2 слоя, FR4 толщиной 1,6 мм, фольга 35 мкм;
- габариты 55,5 × 34,5 мм;
- все компоненты на верхней стороне;
- один полигон GND на всю плату на обоих слоях (общий провод один, без разделения на аналоговую и цифровую землю);
- каждая дорожка одной ширины по всей длине: сигнальные 0,254 мм, питание и GND 0,4 мм (ширина задана в классах цепей Power и GND);
- острых углов нет, повороты дорожек выполнены двумя изломами по 45°, ответвления — под 90°.

Правила завода «Резонит» (уровень «Базовый») записаны в `DZ_SAPR.kicad_dru`. **DRC:** 0 ошибок, 0 неразведённых соединений, 0 несоответствий схеме.

| Параметр | Норма «Резонит» | На плате |
|---|---|---|
| Ширина проводника | ≥ 0,2 мм | 0,254 мм, питание и GND 0,4 мм |
| Зазор | ≥ 0,2 мм | 0,2 мм |
| Металлизированное отверстие | ≥ 0,3 мм | 0,4 мм и более |
| Поясок переходного отверстия | ≥ 0,15 мм | 0,2 мм (отверстия 0,8/0,4 мм), 0,35 мм (1,7/1,0 мм) |
| Поясок монтажной площадки | ≥ 0,2 мм | 0,32–0,40 мм (BK1 — 0,15 мм, уровень «Продвинутый») |
| Медь до края платы | ≥ 0,25 мм | ≥ 0,5 мм |
| Маркировка: шрифт / линия | ≥ 1 мм / ≥ 0,15 мм | 1 мм / 0,15 мм |

**Решения DFMA:**
- односторонний монтаж;
- единый типоразмер пассивных компонентов 0805;
- переходные отверстия 1,0 и 0,4 мм (не меньше нормы завода 0,3 мм);
- разъёмы с шагом 2,54 мм.

## 6. Скрипт ERC, DRC, Gerber, BOM, PDF

`scripts/build.bat` (Windows) и `scripts/build.sh` (Linux / Git Bash) выполняют проверки и выпуск документации. Результаты складываются в папку `output/`:

| Шаг | Результат |
|---|---|
| ERC | `output/erc.rpt` |
| DRC (с проверкой соответствия схеме) | `output/drc.rpt` |
| PDF схемы | `output/DZ_SAPR_schematic.pdf` |
| BOM | `output/DZ_SAPR_bom.csv` |
| Gerber + сверловка | `output/DZ_SAPR_gerbers.zip` |
| 3D-модель | `output/DZ_SAPR.step` |

При ошибках ERC или DRC скрипт останавливается.
